# SecureZip

> This README was generated by AI.

SecureZip is a command-line interface (CLI) tool designed to securely compress and encrypt files. It allows users to create compressed archives of multiple files and optionally encrypt them with a password. Conversely, it supports decrypting and decompressing these archives.

## Features

*   **Compression**: Compresses files to reduce storage space.
*   **Encryption**: Encrypts archives using secure encryption standards (AES-GCM) to protect sensitive data.
*   **Archiving**: Bundles multiple files into a single archive file.
*   **Cross-Platform**: Built with Rust, ensuring performance and reliability across different operating systems.

## Usage

### Compress Files

To compress files into an archive:

```bash
securezip compress <file1> <file2> ... --output <archive_name>
```

To compress and encrypt files:

```bash
securezip compress <file1> <file2> ... --output <archive_name> --encrypt
```
You will be prompted for a password.

### Decompress Files

To decompress an archive:

```bash
securezip decompress <archive_name> --output <destination_folder>
```

If the archive is encrypted, you will be prompted for the password.
