# Simple Rust Chat Application

> This README was generated by AI.

## Überblick

Dieses Projekt ist eine einfache, asynchrone Chat-Anwendung in Rust, bestehend aus drei Teilen:

- **Server:** Verarbeitet TCP-Verbindungen, verwaltet Clients und verteilt Nachrichten an alle Teilnehmer über Broadcast.
- **Client:** Verbindet sich mit dem Server, sendet Eingaben und zeigt empfangene Nachrichten an.
- **Shared:** Gemeinsame Datenstrukturen und Hilfsfunktionen (Nachrichten-Typen, Serialisierung).

Die Anwendung zeigt grundlegende Aspekte von Netzwerkprogrammierung mit `tokio`, Concurrency und JSON-Kommunikation in Rust.

***

## Projektstruktur

```
chat-app/
├── server/      # Chat Server
├── client/      # Chat Client
└── shared/      # Gemeinsame Daten (Message-Types, Serialization)
```

Jedes Teil ist ein eigenständiges Cargo-Crate (Workspace).

***

## Features

- Mehrere Clients gleichzeitig über TCP bedienen
- Nachrichten in JSON serialisieren und via Broadcast an alle senden
- Async Concurrency mit Tokio
- CLI-Client mit Benutzername und Nachrichteneingabe
- Einfache Benutzerverwaltung (Join/Leave Nachrichten)

## Kompilieren und Starten

### Server starten

```bash
cd server
cargo run
```

Standardmäßig lauscht der Server auf `0.0.0.0:8080`.

### Client starten

```bash
cd client
cargo run -- --username DEINNAME --server 127.0.0.1:8080
```

Ersetze `DEINNAME` durch deinen gewünschten Benutzernamen. Mit mehreren Client-Instanzen können mehrere Nutzer chatten.

***

## Nutzung

- Nach Start zeigt der Client eine Eingabeaufforderung.
- Nachrichten tippen und Enter drücken, um sie an alle zu senden.
- Eingabe von `/quit` beendet den Client.
- Der Server informiert alle Teilnehmer über Beitritt und Verlassen eines Nutzers.

## Codeübersicht

- `shared/src/lib.rs`: ChatMessage Struct, Serialisierung/Deserialisierung mit Serde.
- `server/src/main.rs`: Async TCP Server, Broadcast-Kanal, Client-Management.
- `client/src/main.rs`: TCP Client, CLI Argumente mit Clap, parallele Lese- und Schreib-Tasks.
